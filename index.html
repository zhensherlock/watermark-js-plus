Add visible, image, and blind watermarks with a lightweight TypeScript library.

Three watermark APIs

Add watermarks to pages and containers, render them into images, or create and reveal blind watermarks.

Framework agnostic

Use the same browser API with vanilla JavaScript, React, Vue, Angular, Svelte, and other frameworks.

TypeScript first

Use complete public types with flexible styling, lifecycle controls, and optional tamper recovery.
