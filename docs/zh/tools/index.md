# 在线工具

无需先编写集成代码，即可使用以下浏览器工具完成常见水印任务。

## [水印配置生成器](/zh/tools/watermark-configurator)

交互式调整水印参数，在页面中预览效果，并复制自动生成的初始化代码。

## [图片水印工具](/zh/tools/image-watermark)

上传图片，添加文字或图片水印，实时预览并下载 PNG；图片不会上传到服务器。

## [暗水印解码器](/zh/tools/blind-watermark-decoder)

上传或粘贴图片，调整解码参数并显现其中的暗水印。
