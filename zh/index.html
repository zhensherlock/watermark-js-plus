watermark-js-plus适用于任意框架的浏览器水印库

使用轻量的 TypeScript API 添加可见水印、图片水印和暗水印。

开始 👆
在线试用
在 GitHub 上查看

  • 三类水印 API

    为页面和容器添加水印、将水印绘制到图片中，或创建并显现暗水印。

  • 框架无关

    同一套浏览器 API 可用于原生 JavaScript、React、Vue、Angular、Svelte 等前端技术栈。

  • TypeScript 优先

    使用完整公共类型，并获得灵活样式、生命周期控制和可选的防篡改恢复能力。
